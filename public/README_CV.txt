PANDUAN MENYIMPAN FILE CV:

1. Siapkan file CV Anda dalam format PDF.
2. Ubah nama file CV Anda menjadi: cv.pdf
3. Salin dan letakkan file cv.pdf tersebut ke dalam folder "public" ini (d:\Portofolio\public\cv.pdf).

Setelah file diletakkan di sini, tombol "Unduh CV" / "Download CV" di halaman utama website Anda akan otomatis mengunduh atau menampilkan file PDF CV Anda tersebut.
